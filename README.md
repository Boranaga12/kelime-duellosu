# kelime-duellosu

Kelime Düellosu - Çok Oyunculu Kelime ve Hayatta Kalma Oyunu (Flutter).

## Özellikler
- 🎮 Gerçek zamanlı çok oyunculu düello ve özel odalar (2-6 oyuncu, takımlı modlar)
- 🤖 26+ ikonik yapay zeka bot profili (özel replikler ve fotoğraflar)
- 🧠 Yapay Zeka Hakemi (AiRefereeService) ile kendi kendini geliştiren soru havuzu
- 🏆 Kupa, lig, liderlik tablosu ve arkadaşlık sistemi
- 📱 Android ve cross-platform desteği
